# Book Research

A project for researching and documenting book information.

## Paperback grading criteria

Use these standards when setting **grade** on a book. Grade conservatively; when in doubt, grade lower.

The full rubric (grade definitions plus description-parsing hints used by the auto-pricing filter) lives in [`book_catalog/grading.py`](book_catalog/grading.py) — a single source of truth for both the UI and the ChatGPT prompt. Grades, best to worst: **Fine → Near Fine → Very Good → Good → Fair → Poor.**
